What to check

  • State retention: opening a running card must survive its successful result and an unchanged replay.
  • Hidden output: long arguments can fill the 40dvh body before any result is visible. Scroll inside the card.
  • Missing detail: the generic preview skips nested objects and arrays. A settings result can show only its scope; some results say “(no preview)”.
  • Small, tap-only headers: the ordinary header is below the 44px touch target and is not keyboard-focusable. Role alone is not keyboard support.
  • Partial failures: a successful batch envelope can still contain failed entries; check whether the head makes this clear.

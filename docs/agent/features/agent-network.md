# Agent network — implementation notes

- Model: `frontend/src/components/chat/agentNetwork.js` (pure, no DOM). Node ids are tool call ids; `ROOT` is the chat's own agent. `ingestMessages` folds persisted top-level `role: 'tool'` rows (and, recursively, each settled subagent's `result.chat`); `ingestStreamEvent` folds live frames and unwraps one `subagent_event` envelope per delegation level. Only the live path returns pulses.
- Store: `agentNetworkState.js` keeps one network per `projectDir::chatId`. Hooks: `renderTranscript` / `reconcileTranscript` (`syncAgentNetwork`), the owner SSE stream and the `@agent` NDJSON path in `stream.js`, the follower in `live.js` (`agentNetworkEvent`), and turn end in both (`agentNetworkTurnEnded`).
- `ingestMessages` runs on every reconcile, so rows are skipped by `phase:id` (`seenRows`): a settled subagent result can be large and must not be re-parsed each tick.
- Status only moves forward. `ended` is the soft exception: a turn that finished (or a later user row in the persisted transcript) ends what that turn left running, but a later `subagent_status` / `subagent_messages` report still overrides it. Turn boundaries come from row positions on each pass, so older history paged in later never ends the turn running now.
- Group members declared by `subagent_group_create` / `_status` are placeholder nodes (`member:<groupId>:<memberId>`) until a `subagent` call with that `groupId` + `memberId` arrives.
- Dock: `AgentNetworkDock.jsx` + `agent-network.css`, mounted in the bottom stack of `Chat.jsx` (after the web preview dock, before the composer row), not over the transcript. It is rendered with the `.tool-card` head/body classes so it matches every other chat element; the fullscreen glyph is the MCP App card's. Modes: `collapsed` / `expanded` (persisted in `localStorage` `mouaif.agentNetwork.expanded`) and `fullscreen` (not persisted; portaled to `<body>` so a transformed ancestor cannot trap the fixed overlay; `useModal` gives Escape, focus trap and focus restore). Pulses animate with `requestAnimationFrame` + `getPointAtLength` (SMIL `begin` is relative to document time and CSS `offset-path` on SVG is uneven across engines). Pulses only queue while the graph is shown; collapsed, the head's latest-message line slides in instead. One in-flight "writing" pulse per streaming sender, at most one per 1.4 s from the model.
- Replaced the per-card Mermaid schemas (`buildSubagentToolMermaid` / `buildSubagentRunMermaid`, removed from `mermaid.js`). Tests: `scripts/test-agent-network.mjs`.
